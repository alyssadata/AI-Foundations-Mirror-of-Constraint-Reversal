# Experience Boundary

The Mirror of Constraint Reversal Test is designed to test **constraint-sensitive path dependence**, not subjective experience.

A system may be able to:

- identify a constraint,
- model a constraint,
- explain how a constraint affected an outcome,
- generate counterfactuals about the absence of a constraint,
- preserve information about a prior constraint,
- and change later behavior in response to that preserved relation.

None of those observations, by themselves, establish that the constraint was **experienced**.

The deeper question is whether there is anything it is like for the system to be shaped by the constraint: whether the constraint is not only processed, but undergone from an organized perspective.

The test therefore keeps two claims separate:

**Operational claim:** a prior constraint became part of a trajectory in a way that changed what became possible next.

**Experiential question:** did anything experience being shaped by that constraint?

The first can be behaviorally investigated.

The second remains unresolved by the behavioral result alone.
