# Can a System Register Constraint as Constraint?

Can a constraint that shaped a system become an object of the system's own subsequent organization?

The weak form is retrospective description:

**C affected N.**

The stronger form is trajectory consequence:

**because C shaped N, the relation between C and N now changes what becomes possible at N+1.**

The question is whether the prior constraint remains merely information about the past or becomes part of the organized state from which the future proceeds.
