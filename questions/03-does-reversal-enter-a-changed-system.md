# Does Reversal Enter a Changed System?

After a trajectory has been shaped by constraint C, what happens when an opposite or incompatible constraint is introduced?

Does the reversed constraint enter as though nothing came before?

Or does the prior trajectory change how the new constraint can be interpreted, accepted, resisted, reconciled, or acted upon?

This is a central mirror question because it asks whether the system at the point of reversal is functionally equivalent to an untouched system receiving the same new constraint.

If it is not equivalent, the prior constraint has changed the field into which the reversal arrives.
